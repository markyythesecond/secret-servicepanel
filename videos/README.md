# Drop your videos here

Upload `.mp4`, `.webm` or `.mov` files into this folder (Add file → Upload files)
and they appear on the site automatically after GitHub Pages redeploys (~1 minute).

- Subfolders become categories: `videos/Funny/clip.mp4` → "Funny"
- Custom thumbnail: put an image with the same name next to the video
  (`clip.mp4` + `clip.jpg`). Otherwise a frame is grabbed automatically.
- The file name is the title: `my_cool-clip.mp4` → "my cool clip"
- Max 25 MB per file through the website upload, 100 MB with git.
